# MODULOS Agency Website

A responsive, multi-page static website for Modulos.

## Files
- `index.html` — homepage
- `development.html` — development services
- `designing.html` — design services
- `video-editing.html` — video editing
- `social-media-marketing.html` — marketing
- `youtube-production.html` — YouTube production
- `gaming-support.html` — gaming support
- `contact.html` — contact page
- `style.css`, `script.js` — shared styles and interactions
- `modulos.logo.png` — add your supplied logo here (root folder)

## Launch checklist
1. Put your actual `modulos.logo.png` in this folder. The ZIP contains a placeholder note only because no logo image was supplied in this chat.
2. Replace the sample Unsplash images with licensed brand photography if desired.
3. Update canonical URLs if the production domain is not `https://modulos.in`.
4. The contact form currently creates a pre-filled email using `mailto:`. For reliable form delivery, connect a serverless/API endpoint and add spam protection before launch.
5. Add a real business address before publishing a location pin. The map currently shows India generally and does not claim to be an office location.
6. Configure hosting with HTTPS and ensure all eight HTML files are deployed at the site root.
7. Add `robots.txt`, `sitemap.xml`, analytics/consent configuration and Search Console verification for your production deployment.

## Notes
- Pure CSS (Grid/Flexbox), vanilla JavaScript, Google Fonts and Font Awesome CDN.
- No Bootstrap, Tailwind, Firebase or Cloudflare.
- Includes unique title/description/canonical/OG/Twitter metadata and JSON-LD schema per page.
- FAQ content is included on each page and its content is visible to users. FAQ rich-result display is controlled by search engines and is not guaranteed.
